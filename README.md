# 📝 Word Counter – Python Programming Internship

## 📌 Project Overview
The Word Counter is a simple text analysis project developed as part of my Python Programming Internship at **SAM AI Technologies**.

The project uses Python to read text from a file, process its contents, and calculate the total number of words. I also created an interactive web interface using HTML, CSS, and JavaScript to make text analysis more user-friendly.

## ✨ Features

### Python Implementation
- Reads text from a `.txt` file.
- Splits the content into individual words.
- Calculates the total word count.
- Handles missing files using `FileNotFoundError`.
- Includes exception handling for unexpected errors.

### Web Interface
- Interactive and user-friendly design.
- Live word count.
- Live character count.
- Sentence count.
- Clear Text functionality.
- Instant text analysis.

## 🛠️ Technologies Used
- **Python** – File handling and word counting.
- **HTML** – Webpage structure.
- **CSS** – Styling and user interface.
- **JavaScript** – Live text analysis and interactivity.

## 🚀 How to Run the Python Program

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Ensure `sample.txt` is in the same folder as `python.py`.
5. Open the terminal.
6. Execute:

```bash
python python.py
```

7. The total word count will be displayed in the terminal.

## 🌐 How to Run the Web Interface

1. Open the project folder in VS Code.
2. Locate `index.html`.
3. Right-click and select **Open with Live Server** (if installed).
4. Enter or paste text into the text area.
5. View the live word, character, and sentence counts.
